\# Demo Web Shop Automation Tests



Автоматизированные тесты для сайта https://demowebshop.tricentis.com



\## Стек



\- Playwright

\- JavaScript

\- Node.js



\## Что проверяется



\### Функциональное тестирование



\- регистрация пользователя

\- авторизация пользователя

\- выход из аккаунта

\- проверка сообщений об ошибках

\- валидация полей



\### API-тестирование



\- проверка статус-кодов

\- проверка ответов API

\- валидация данных



\### Тестирование безопасности



\- доступ к защищённым страницам

\- работа сессий

\- обработка некорректных данных



\## Статистика



\- 13 функциональных тестов

\- 4 API-теста

\- 18 тестов авторизации и безопасности



Всего: 35 тестов



\## Запуск проекта



Установка зависимостей:



```bash

npm install

```



Запуск тестов:



```bash

npx playwright test

```



\## Результат
